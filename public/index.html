⏰ Chrono-DNI Safety API
💡 DNI(Drug-Nutrient Interaction)란?
처방약과 특정 영양 성분(칼슘, 철분, 비타민 등)이 몸속에서 서로 만나 약효가 떨어지거나 장기에 부담을 주는 '약물-영양소 체내 충돌(상극 반응)'을 의미합니다. 서온은 이 충돌을 피할 수 있는 안전한 투약 시간대를 계산해 드립니다.

상극 충돌 방지 24시간 안전 투약 스케줄 연산 모듈

처방약과 영양 성분 간 킬레이트 결합·흡수 방해 요소를 실시간 분석해 시간대별 안전 투약 스케줄을 산출해요.

※ 서온은 수의사의 직접적인 진료나 처방을 대신하지 않으며, 수의영양학 및 약학 수식 데이터를 기반으로 한 비진단(Non-Diagnostic) 의사결정 보조 API입니다.

API SPECIFICATION

        

          

            
Request

            

              
                
Base URLhttps://seon-api-orb2.onrender.com

                
EndpointPOST /v1/analyze

                
Request Bodypet_bio (breed, weight_kg, age_years, bcs, conditions) · prescriptions · supplements

                
Auth HeaderX-SEON-API-KEY: <YOUR_PARTNER_KEY>

                
Content-Typeapplication/json

                
Latency SLASub-20ms target (server-side compute, p50)

                
Rate Limit60 req/min (Sandbox) · Production은 계약 조건에 따라 조정

                
InteroperabilityHL7/FHIR 호환 응답 매핑 (fhir_compatible: true)

              
            

          

          

            
Response Codes

            

              
CodeMeaning

              
                
200OK — 분석 성공

                
400Bad Request — 필수 파라미터 누락

                
401Unauthorized — API Key 누락 또는 유효하지 않음

                
422Unprocessable — 성분명·수치를 인식할 수 없음

                
429Rate Limit — 요청 한도 초과

                
500Server Error — 일시적 오류 (재시도 권장)

              
            

          

          

            
Response Fields

            

              
FieldDescription

              
                
ndc_codeU.S. National Drug Code 식별자 매핑 (예: NDC 50320-012-10)

                
health_score목표 건강 스코어 (0–100)

                
hepatic_strain_index간 대사 부하 지수 (%)

                
renal_clearance_burden신장 여과 부담 지수 (%)

                
isolation_hoursDNI 상극 회피를 위한 격리 복용 시간 (h)

                
fhir_compatibleHL7/FHIR 수의 EMR 포맷 연동 호환 여부

              
            

          

          
※ Live API Sandbox 탭은 위 엔드포인트를 실제로 호출해요(서버가 유휴 상태였다면 첫 응답은 수십 초 걸릴 수 있어요). Sandbox의 ndc_code는 데모용 매핑이며, 프로덕션에서는 공인 NDC 디렉터리와 매칭돼요.
